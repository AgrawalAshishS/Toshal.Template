ParserException

class in Toshal.Template.Exceptions, assembly Toshal.Template

Thrown by Parse when the template text is not valid. It is also the base class of the more specific parser exceptions. It is thrown as this exact type for an unknown tag (for example <%FOO%>, or an <%ENDIF%> without IF), an unknown block inside a FOREACH, and a <%REMOVE_PREVIOUS n%> whose n is not a whole number or is negative, and two FOREACH blocks with the same id attribute.

Example

try { new Parser().Parse(text); }
catch (ParserException ex) { Console.WriteLine($"Line {ex.LineNumber}, column {ex.StartingPosition}: {ex.Message}"); }
