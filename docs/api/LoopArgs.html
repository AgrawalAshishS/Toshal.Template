LoopArgs

class in Toshal.Template, assembly Toshal.Template

The arguments of LoopValueProvider for a <%FOREACH name%> or <%REUSE_FOREACH existing name%> tag.

Example

processor.LoopValueProvider = args => args.Name == "lines" ? ((Order)args.Context!).Lines : null;

Constructors

LoopArgs(LoopArgs args, object context)

Creates arguments for a child object: same name and attributes, a new context, and the old context added at the end of a copy of the parent contexts. Use it when a provider hands part of the work to another provider.

Parameters

args
The arguments to copy. They are not changed.
context
The new context. It can be null.

Example

var child = new LoopArgs(args, order.Customer);   // child.ParentContext ends with order
LoopArgs(ForEachToken token, object context, List<object> parentContext)

Creates the arguments for a FOREACH tag. The processor calls it; you need it only to test a provider on its own.

Parameters

token
The parsed FOREACH tag. Its name and attributes are copied.
context
The current context. It can be null.
parentContext
The contexts around the tag, outermost first. It is stored as is, not copied.

Example

var token = (ForEachToken)new Parser().Parse("<%FOREACH lines%>x<%ENDFOR%>")[0];
IList? rows = myProvider(new LoopArgs(token, order, new List<object?> { order }));
LoopArgs(string loopName, object context, List<object> parentContext, TokenAttributeDictionary attributes)

Creates the arguments with a name and attributes given directly. The processor uses it for REUSE_FOREACH: the name is the new name and the attributes come from the reused FOREACH.

Parameters

loopName
The name of the loop, in lower case.
context
The current context. It can be null.
parentContext
The contexts around the tag, outermost first. It is stored as is, not copied.
attributes
The attributes of the loop. It is stored as is, not copied.

Example

var args = new LoopArgs("lines", order, new List<object?> { order }, new TokenAttributeDictionary());
