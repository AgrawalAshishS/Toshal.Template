IWithValueProvider

interface in Toshal.Template.Signatures, assembly Toshal.Template

The shape of a class that gives the context of WITH blocks. Its method matches WithValueProvider.

Remarks

The Processor does not use this interface; it has delegate properties. The interface is a ready made shape for a provider class: implement it, then assign the method to the matching property of the processor.

Example

processor.WithValueProvider = myProvider.WithValueProvider;

Methods

object WithValueProvider(TokenArgs args)

Gives the object that becomes the context inside the named WITH block.

Parameters

args
The name, attributes and contexts of the WITH tag.

Returns

The new context. Null skips the whole block.

Example

public object? WithValueProvider(TokenArgs args) => ((Order)args.Context!).Customer;
