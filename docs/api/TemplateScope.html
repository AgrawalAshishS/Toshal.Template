TemplateScope

class in Toshal.Template.Compiled, assembly Toshal.Template.Compiled

The SET variables of one block of a compiled template. Generated code uses it; you do not need it in your own code.

Remarks

A child scope sees the variables of its parent and copies them only when a SET in it writes, the same way as Processor.

Example

// Generated code for <%WITH customer%>...<%ENDWITH%>:
var withScope = TemplateScope.Child(scope);

Methods

static TemplateScope Child(TemplateScope parent)

Makes a scope for an inner block. It sees the variables of parent; a SET in it is not seen by the parent.

Parameters

parent
The scope of the outer block.

Returns

The new scope. It allocates nothing until a SET writes.

Example

var rowScope = TemplateScope.Child(scope);
