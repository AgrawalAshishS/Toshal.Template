GlobalProvider

abstract class in Toshal.Template.Providers, assembly Toshal.Template

Answers names that do not depend on the type of the current context, such as a project name, a version or today's date. It is asked for every context, also when the context is null. Register it with RegisterGlobal.

Remarks

Each method returns true when it handled the name, even when the value is null, empty or false. Return false to let the next provider try.

Warning: a global provider runs for every tag of its kind, so keep it short: one switch on Name. It is called from many threads when you process templates in parallel.

Example

sealed class ProjectGlobals : GlobalProvider
{
    public override bool TryToken(TokenArgs args, out string? value)
    {
        switch (args.Name)
        {
            case "project_name": value = "Shop"; return true;
        }

        value = null;
        return false;
    }
}

bool TryWrite(TokenArgs args, StringBuilder output)

Answers <%=name%> by appending the value straight to the output. The default calls TryToken and appends its value.

Parameters

args
The name, the attributes, the context (it can be null) and the parent contexts of the tag.
output
The text written so far. Append to it.

Returns

true when this provider handled the name; false to let the next provider try.

Remarks

Warning: return false only when you wrote nothing, and never remove text that is already in output.

Example

public override bool TryWrite(TokenArgs args, StringBuilder output)
{
    switch (args.Name)
    {
        case "current_year": output.Append(DateTime.Now.Year); return true;
    }

    return base.TryWrite(args, output);
}
