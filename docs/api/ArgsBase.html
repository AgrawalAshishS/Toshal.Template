ArgsBase

abstract class in Toshal.Template, assembly Toshal.Template

The common part of the arguments that the Processor passes to its value providers: the name of the tag, the current context and the contexts around it.

Example

processor.TokenValueProvider = args => args.Name == "name" ? ((Customer)args.Context!).Name : null;

Constructors

ArgsBase(string name, object context, List<object> parentContext)

Sets the name, the context and the parent contexts. Only the derived argument classes call it.

Parameters

name
The name of the tag, in lower case. For <%=Name%> it is name.
context
The current context object. It can be null.
parentContext
The list of contexts around the tag, outermost first. It is stored as is, not copied.

Example

var args = new TokenArgs(token, customer, new List<object?> { customer });

Methods

T FindParent<T>()

Finds the nearest entry of type in ParentContext, searching from the inside (the last entry) out. The current context is normally the last entry, so it is found first when it matches.

Returns

The nearest matching entry, or null when there is none.

Remarks

A plain loop with a type check: no reflection, no allocation.

Example

// Inside a FOREACH of columns inside a FOREACH of insert queries.
var query = args.FindParent<InsertQuery>();
object Parent(int levelsUp)

Gets the entry of ParentContext that is levelsUp levels above the last entry. Parent(0) is the last entry (normally the current context). Inside a FOREACH row, Parent(1) is the list of the loop.

Parameters

levelsUp
How many entries to go up from the last one. 0 or more.

Returns

The entry, or null when the list has fewer entries.

Exceptions

ArgumentOutOfRangeException
levelsUp is negative.

Example

// Inside a FOREACH row: the whole list.
var rows = (IList?)args.Parent(1);
