SeparatorToken

class in Toshal.Template.Tokens, assembly Toshal.Template

A parsed <%SEPARATOR%>...<%ENDSEPARATOR%> block. The processor writes its inner part in every row of the innermost FOREACH except the last one, like the separator of string.Join.

Remarks

It may stand anywhere in a row: in the ROW, ALTROW, FIRSTROW or LASTROW part, in a BEFORE or AFTER part, or inside an IF or WITH in the row. In a HEADER, FOOTER or NORECORD part, or outside any FOREACH, it writes nothing. It also works in a sub template that a row calls with PROCESS_TEMPLATE.

Unlike <%REMOVE_PREVIOUS n%> it counts no characters, so it works the same with \n and \r\n line breaks.

Example

// public Customer(
//     int id,
//     string email
// )
var tokens = new Parser().Parse(
    "public Customer(\n    <%FOREACH fields%>\n    <%=type%> <%=name%><%SEPARATOR%>,<%ENDSEPARATOR%>\n    <%ENDFOR%>\n)\n");
