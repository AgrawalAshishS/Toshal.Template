IConditionValueProvider

interface in Toshal.Template.Signatures, assembly Toshal.Template

The shape of a class that answers IF and ELSEIF conditions. Its method matches ConditionValueProvider.

Remarks

The Processor does not use this interface; it has delegate properties. The interface is a ready made shape for a provider class: implement it, then assign the method to the matching property of the processor.

Example

processor.ConditionValueProvider = myProvider.ConditionValueProvider;

Methods

bool ConditionValueProvider(ConditionArgs args)

Says whether the named condition is true for the current context.

Parameters

args
The name, attributes and contexts of the IF or ELSEIF tag.

Returns

True when the condition holds. For <%IF not name%> return the value of name; the processor applies the not.

Example

public bool ConditionValueProvider(ConditionArgs args) => args.Name == "paid" && ((Invoice)args.Context!).Paid;
