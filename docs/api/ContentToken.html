ContentToken

class in Toshal.Template.Tokens, assembly Toshal.Template

Plain text of the template, outside any tag. The processor writes it as it is.

Example

var text = (ContentToken)new Parser().Parse("Hello <%=Name%>")[0];   // text.Content == "Hello "

Constructors

ContentToken(Split split)

Creates the token from a piece of plain text. The parser calls it.

Parameters

split
The text piece. Its content, line and column are copied.

Example

var token = new ContentToken(new Split { Content = "Hello " });
