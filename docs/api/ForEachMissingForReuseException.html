ForEachMissingForReuseException

class in Toshal.Template.Exceptions, assembly Toshal.Template

Thrown by Parse when <%REUSE_FOREACH existing name%> names a FOREACH that is nowhere in the template. The nearest FOREACH is used first (own level, then outer levels), then the first one in the whole template. Split is null for this exception; the line and column are those of the REUSE_FOREACH tag.

Example

try { new Parser().Parse("<%REUSE_FOREACH lines copy%>"); }
catch (ForEachMissingForReuseException ex) { Console.WriteLine(ex.ForEachName); }   // lines
