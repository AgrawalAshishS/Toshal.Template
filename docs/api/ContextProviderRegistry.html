ContextProviderRegistry

class in Toshal.Template.Providers, assembly Toshal.Template

Picks the providers for a tag by the type of the current context, so each provider sees only its own type. It replaces a long chain of "try this provider, then that one" with one lookup by type. Its Token, Condition, Loop and With methods fit the provider properties of Processor; AttachTo sets all four.

Remarks

The order for one tag:

The first provider that handles the name wins, even with a null, empty or false value. When no provider handles it, a token, loop and with get null and a condition gets false.

Speed: the list of providers for a type is built once, on the first tag with a context of that type, and then cached. Each later tag costs one dictionary lookup on the type and one call per provider tried. No reflection runs while processing, and nothing is allocated.

Warning: register every provider before the first lookup. After it, Register``1 and RegisterGlobal throw. Lookups are safe from many threads at once.

Example

var registry = new ContextProviderRegistry()
    .Register(new CustomerProviderCustom())   // hand written: asked first
    .Register(new CustomerProvider())         // generated
    .Register(new OrderProvider())
    .RegisterGlobal(new ProjectGlobals(), GlobalOrder.BeforeTyped);

var processor = new Processor();
registry.AttachTo(processor);
string text = processor.Process(new ProcessorArgs(tokens) { Context = customer }).ToString();

void AttachTo(Processor processor)

Sets TokenWriter, TokenValueProvider, ConditionValueProvider, LoopValueProvider and WithValueProvider to this registry. ProcessTemplateValueProvider is not changed. The processor uses the writer, so values are appended straight to the output.

Parameters

processor
The processor to set.

Exceptions

ArgumentNullException
processor is null.

Example

var processor = new Processor { ProcessTemplateValueProvider = args => templates[args.Name] };
registry.AttachTo(processor);

string Token(TokenArgs args)

Answers <%=name%> with the first provider that handles the name. It fits TokenValueProvider. Each provider is asked with TryToken first, which makes no copy, and then with TryWrite, so a name that a provider only writes is answered too, with the same text as Write.

Parameters

args
The arguments from the processor.

Returns

The text, or null when no provider handled the name.

Exceptions

ArgumentNullException
args is null.

Remarks

AttachTo sets TokenWriter too, and the processor then uses Write, which makes no string. Use this method when you need the value as a string.

Example

processor.TokenValueProvider = registry.Token;
