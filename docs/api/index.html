Toshal.Template

TypeSummary
ArgsBaseThe common part of the arguments that the Processor passes to its value providers: the name of the tag, the current context and the contexts around it.
ConditionArgsThe arguments of ConditionValueProvider for an <%IF name%> or <%ELSEIF name%> tag.
LoopArgsThe arguments of LoopValueProvider for a <%FOREACH name%> or <%REUSE_FOREACH existing name%> tag.
ParserTurns template text into a list of tokens. Parse a template once and give the tokens to Process as often as you like.
ProcessorTurns parsed tokens into text. The data comes from five provider delegates that you set: one for each kind of tag that needs data. The processor does not read properties by reflection; your providers decide what each name means.
ProcessorArgsThe input of Process: the parsed template and the top context object.
ProcessTemplateArgsThe arguments of ProcessTemplateValueProvider for a <%PROCESS_TEMPLATE name%> tag.
SplitOne piece of the template text as the parser cuts it: either a whole tag such as <%=Name%> or the plain text between tags. Token constructors read it, and Split points to the piece that failed.
TokenArgsThe arguments of TokenValueProvider for a <%=name%> tag, and of WithValueProvider for a <%WITH name%> tag.

Toshal.Template.Exceptions

TypeSummary
ForEachMissingForReuseExceptionThrown by Parse when <%REUSE_FOREACH existing name%> names a FOREACH that is nowhere in the template. The nearest FOREACH is used first (own level, then outer levels), then the first one in the whole template. Split is null for this exception; the line and column are those of the REUSE_FOREACH tag.
InvalidTokenAttributeExceptionThrown by Parse when the attributes of a tag are not written as name="value", for example <%=Total format=0.00%> or <%=Total format = "0.00"%>, or when a tag has the same attribute twice.
ParserExceptionThrown by Parse when the template text is not valid. It is also the base class of the more specific parser exceptions. It is thrown as this exact type for an unknown tag (for example <%FOO%>, or an <%ENDIF%> without IF), an unknown block inside a FOREACH, and a <%REMOVE_PREVIOUS n%> whose n is not a whole number or is negative, and two FOREACH blocks with the same name at the same level.
TokenMissingNameExceptionThrown by Parse when a tag that needs a name has none, for example <%=%>, <%IF %> or <%FOREACH %>.
TokenNotClosedExceptionThrown by Parse when a block has no end tag: IF without ENDIF, FOREACH without ENDFOR, WITH without ENDWITH, SET without ENDSET, or a FOREACH part such as <%ROW%> without <%ENDROW%>.

Toshal.Template.Signatures

TypeSummary
IConditionValueProviderThe shape of a class that answers IF and ELSEIF conditions. Its method matches ConditionValueProvider.
ILoopValueProviderThe shape of a class that gives the rows of FOREACH and REUSE_FOREACH loops. Its method matches LoopValueProvider.
IProcessTemplateValueProviderThe shape of a class that gives the sub templates of PROCESS_TEMPLATE tags. Its method matches ProcessTemplateValueProvider.
ITokenValueProviderThe shape of a class that gives the text of <%=name%> tags. Its method matches TokenValueProvider.
IWithValueProviderThe shape of a class that gives the context of WITH blocks. Its method matches WithValueProvider.

Toshal.Template.Tokens

TypeSummary
ConditionTokenA parsed <%IF name%> or <%ELSEIF name%> tag with the tokens of its true part. The word THEN at the end is optional: <%IF paid THEN%> is the same as <%IF paid%>. <%IF not paid%> is a negative condition.
ContainerTokenBaseThe base class of tokens that hold other tokens: ConditionToken, ElseToken, SetToken and WithToken.
ContentTokenPlain text of the template, outside any tag. The processor writes it as it is.
ContextAsStringTokenA parsed <%CONTEXT_AS_STRING%> tag. The processor writes ToString() of the current context, or nothing when the context is null. It needs no provider, so it is handy for a list of strings or numbers.
ElseTokenThe <%ELSE%> part of an IF block. It is the FalsePart of the last IF or ELSEIF.
ForEachTokenA parsed <%FOREACH name%> ... <%ENDFOR%> block. It has one token list for each part that a loop can have. Each part is written as <%PART%> ... <%ENDPART%> inside the block, for example <%HEADER%> ... <%ENDHEADER%>, and each part may appear once. Text and tags inside the block but outside every part belong to the ROW part. The FOREACH name is unique per level; see Parser.
IContainerTokenA token that holds other tokens. FalsePart has this type.
ITokenOne parsed part of a template: plain text or a tag. Parse returns a list of them, and Process turns the list into text.
NamedTokenA parsed <%=name%> value tag, with optional attributes such as <%=Total format="0.00"%>. The processor writes the value of a SET variable with this name, or else the text from TokenValueProvider.
ProcessTemplateTokenA parsed <%PROCESS_TEMPLATE name%> tag. The processor asks ProcessTemplateValueProvider for the tokens of the named sub template and processes them in place, with the current context. The sub template sees the SET variables of the caller, and its own SET variables stay inside it.
RemovePreviousCharsTokenA parsed <%REMOVE_PREVIOUS n%> tag. The processor removes the last n characters written so far, or all of them when fewer were written. It is useful to drop a trailing separator, such as the last comma of a list.
RemovePreviousNewLineTokenA parsed <%REMOVE_PREVIOUS_NEW_LINE%> tag. The processor removes a \n at the end of the text written so far, and then a \r at the end. It lets you keep each tag on its own line in the template without empty lines in the output.
ReuseForEachTokenA parsed <%REUSE_FOREACH existing name%> tag. It runs the FOREACH block named existing again, at this place, under the new name. The loop value provider is asked for the rows with the new name and the attributes of the existing FOREACH, so the same layout can show a different list. The parser links the nearest FOREACH with that name: at the level of this tag first (before or after it), then at each outer level. When none has the name, it links the first FOREACH with that name in the whole template, top to bottom.
SetTokenA parsed <%SET name%> ... <%ENDSET%> block. The processor writes the inner tokens into a variable instead of the output. A later <%=name%> writes the variable, and the variable wins over the token value provider.
TokenThe base class of all tokens. It holds the position of the token in the template.
TokenAttributeDictionaryThe attributes of a tag, such as format="0.00" in <%=Total format="0.00"%>. Keys are the attribute names in lower case. Values keep the case the template author wrote, in every tag. A quoted value may contain spaces.
WithTokenA parsed <%WITH name%> ... <%ENDWITH%> block. The processor asks WithValueProvider for an object, and that object is the context of the tags inside the block. When the provider returns null the whole block is skipped.
