ContextProvider<T>

abstract class in Toshal.Template.Providers, assembly Toshal.Template

Answers the tags for one type of context. Register it with Register``1. Override only the methods you need; the others answer "not handled".

Remarks

Each method returns true when it handled the name, even when the value is null, empty or false. The registry then stops and uses that value. Return false to let the next provider try.

No reflection is used. Write a switch on Name; the compiler turns a string switch into a fast lookup.

Warning: the registry calls the provider from many threads when you process templates in parallel. Do not keep state in it that changes.

Example

sealed class CustomerProvider : ContextProvider<Customer>
{
    public override bool TryToken(Customer context, TokenArgs args, out string? value)
    {
        switch (args.Name)
        {
            case "name": value = context.Name; return true;
        }

        value = null;
        return false;
    }
}

bool TryWrite(T context, TokenArgs args, StringBuilder output)

Answers <%=name%> by appending the value straight to the output, so no string is made for numbers, dates or text joined from parts. The default calls TryToken and appends its value. The processor uses this method through Write; Token uses it too and returns the text.

Parameters

context
The current context, already of type . Never null.
args
The name, the attributes and the parent contexts of the tag.
output
The text written so far. Append to it.

Returns

true when this provider handled the name; false to let the next provider try.

Remarks

Warning: return false only when you wrote nothing, and never remove text that is already in output. Override it for the names you can append directly and call base.TryWrite for the rest, so TryToken still answers them.

Example

public override bool TryWrite(Order context, TokenArgs args, StringBuilder output)
{
    switch (args.Name)
    {
        case "line_count": output.Append(context.Lines.Count); return true;
    }

    return base.TryWrite(context, args, output);
}
