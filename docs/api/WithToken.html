WithToken

class in Toshal.Template.Tokens, assembly Toshal.Template

A parsed <%WITH name%> ... <%ENDWITH%> block. The processor asks WithValueProvider for an object, and that object is the context of the tags inside the block. When the provider returns null the whole block is skipped.

Example

// <%WITH Customer%>Dear <%=Name%>,<%ENDWITH%>
processor.WithValueProvider = args => args.Name == "customer" ? ((Order)args.Context!).Customer : null;

Constructors

WithToken(Split split)

Reads the name and attributes of the tag. The parser calls it and then fills InnerTokens.

Parameters

split
The WITH tag.

Exceptions

The tag has no name.
InvalidTokenAttributeException
The attributes are not written as name="value".

Example
