TokenArgs

class in Toshal.Template, assembly Toshal.Template

The arguments of TokenValueProvider for a <%=name%> tag, and of WithValueProvider for a <%WITH name%> tag.

Remarks

Warning: within one Process call the processor reuses one TokenArgs object for every value and WITH tag, so it is valid only while your provider runs. Do not keep it; read the values you need while the provider runs.

Example

processor.TokenValueProvider = args => args.Name switch
{
    "total" => ((Order)args.Context!).Total.ToString(args.GetAttribute("format", "0.00")),
    _ => null,
};

Constructors

TokenArgs(TokenArgs args, object context)

Creates arguments for a child object: same name and attributes, a new context, and the old context added at the end of a copy of the parent contexts. Use it when a provider hands part of the work to another provider.

Parameters

args
The arguments to copy. They are not changed.
context
The new context. It can be null.

Example

// "customer.name": hand "name" to the customer provider with the customer as context.
string? name = customerProvider(new TokenArgs(args, order.Customer));
TokenArgs(NamedToken token, object context, List<object> parentContext)

Creates the arguments for a value tag. The processor calls it; you need it only to test a provider on its own.

Parameters

token
The parsed value tag. Its name and attributes are copied.
context
The current context. It can be null.
parentContext
The contexts around the tag, outermost first. It is stored as is, not copied.

Example

var token = (NamedToken)new Parser().Parse("<%=total%>")[0];
string? text = myProvider(new TokenArgs(token, order, new List<object?> { order }));
TokenArgs(WithToken token, object context, List<object> parentContext)

Creates the arguments for a WITH tag. The processor calls it; you need it only to test a provider on its own.

Parameters

token
The parsed WITH tag. Its name and attributes are copied.
context
The current context. It can be null.
parentContext
The contexts around the tag, outermost first. It is stored as is, not copied.

Example

var token = (WithToken)new Parser().Parse("<%WITH customer%>x<%ENDWITH%>")[0];
object? value = myProvider(new TokenArgs(token, order, new List<object?> { order }));

Methods

string GetAttribute(string key, string defaultValue)

Gets an attribute value, or a default when the tag does not have that attribute. The key is not case sensitive.

Parameters

key
The attribute name.
defaultValue
The value to return when the attribute is missing.

Returns

The attribute value as written in the tag, or defaultValue.

Exceptions

ArgumentNullException
key is null.

Example

// <%=Total format="0.00"%>
string format = args.GetAttribute("Format", "0");   // "0.00"
