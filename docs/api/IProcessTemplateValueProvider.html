IProcessTemplateValueProvider

interface in Toshal.Template.Signatures, assembly Toshal.Template

The shape of a class that gives the sub templates of PROCESS_TEMPLATE tags. Its method matches ProcessTemplateValueProvider.

Remarks

The Processor does not use this interface; it has delegate properties. The interface is a ready made shape for a provider class: implement it, then assign the method to the matching property of the processor.

Example

processor.ProcessTemplateValueProvider = myProvider.ProcessTemplateValueProvider;

Methods

Gives the parsed sub template for the named PROCESS_TEMPLATE tag.

Parameters

args
The name, attributes and contexts of the tag.

The tokens of the sub template, from Parse. Null writes nothing.
