ReuseForEachToken

class in Toshal.Template.Tokens, assembly Toshal.Template

A parsed <%REUSE_FOREACH existing name%> tag. It runs the FOREACH block named existing again, at this place, under the new name. The loop value provider is asked for the rows with the new name and the attributes of the existing FOREACH, so the same layout can show a different list. The existing FOREACH must be in the same template; it can come before or after this tag.

Example

// Same table layout for two lists:
// <%FOREACH open%>- <%=Title%><%ENDFOR%>  Done: <%REUSE_FOREACH open done%>

Constructors

ReuseForEachToken(Split split)

Reads the existing FOREACH name and the new name from the tag. The parser calls it and later sets ExistingForEachToken.

Parameters

split
The tag.

Exceptions

TokenMissingNameException
The tag does not have both names.

Example

var token = new ReuseForEachToken(new Split { Content = "<%REUSE_FOREACH open done%>" });
