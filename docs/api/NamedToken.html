NamedToken

class in Toshal.Template.Tokens, assembly Toshal.Template

A parsed <%=name%> value tag, with optional attributes such as <%=Total format="0.00"%>. The processor writes the value of a SET variable with this name, or else the text from TokenValueProvider.

Example

var token = (NamedToken)new Parser().Parse("<%=Total format=\"0.00\"%>")[0];
// token.Name == "total", token.GetAttribute("format", "") == "0.00"

Parameters

Exceptions

Gets an attribute value, or a default when the tag does not have that attribute. The name is not case sensitive.

Parameters

attributeName
The attribute name.
defaultValue
The value to return when the attribute is missing.

Returns

The attribute value as written in the tag, or defaultValue.

Exceptions

Example
