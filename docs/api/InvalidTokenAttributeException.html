InvalidTokenAttributeException

class in Toshal.Template.Exceptions, assembly Toshal.Template

Thrown by Parse when the attributes of a tag are not written as name="value", for example <%=Total format=0.00%> or <%=Total format = "0.00"%>, or when a tag has the same attribute twice.

Example

Assert.Throws<InvalidTokenAttributeException>(() => new Parser().Parse("<%=Total format=0.00%>"));

Constructors

Creates the exception for the tag that has the bad attributes.
