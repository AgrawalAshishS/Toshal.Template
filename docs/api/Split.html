Split

class in Toshal.Template, assembly Toshal.Template

One piece of the template text as the parser cuts it: either a whole tag such as <%=Name%> or the plain text between tags. Token constructors read it, and Split points to the piece that failed.

Remarks

This is a parser detail that is public. It is documented as it is; code outside the library rarely needs it.

Example

var token = new NamedToken(new Split { Content = "<%=Name%>", LineNumber = 1, StartingPosition = 1 });

Fields

string Content

The text of the piece, including <% and %> for a tag. The default is an empty string.

Example

catch (ParserException ex) { Console.WriteLine(ex.Split?.Content); }
int LineNumber

The 1 based line of the first character of the piece. The default is 0.

Example

int line = split.LineNumber;
int StartingPosition

The 1 based column of the first character of the piece. The default is 0.

Example

int column = split.StartingPosition;
