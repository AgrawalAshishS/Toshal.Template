ForEachToken

class in Toshal.Template.Tokens, assembly Toshal.Template

A parsed <%FOREACH name%> ... <%ENDFOR%> block. It has one token list for each part that a loop can have. Each part is written as <%PART%> ... <%ENDPART%> inside the block, for example <%HEADER%> ... <%ENDHEADER%>, and each part may appear once. Text and tags inside the block but outside every part belong to the ROW part.

Remarks

For each row the processor picks the parts like this: on odd rows (the second, fourth, ...) the ALT parts are used when they are not empty. On the first row of a list with more than one row, the FIRST parts win. On the last row, the LAST parts win. An empty part is ignored and the earlier choice stays, so an odd last row with no LASTROW part uses ALTROW, or ROW when ALTROW is empty too.

Warning: by design the LAST parts win: a list with one row uses BEFORELASTROW, LASTROW and AFTERLASTROW, and never the FIRST parts.

Example

<%FOREACH lines%>
  <%HEADER%>Item  Qty<%ENDHEADER%>
  <%ROW%><%=Item%>  <%=Qty%><%ENDROW%>
  <%NORECORD%>No lines<%ENDNORECORD%>
<%ENDFOR%>

Constructors

ForEachToken(Split split)

Reads the name and attributes of a FOREACH tag and creates empty part lists. The parser calls it and then fills the parts.

Parameters

split
The FOREACH tag.

Exceptions

TokenMissingNameException
The tag has no name, for example <%FOREACH %>.
InvalidTokenAttributeException
The attributes are not written as name="value".

Example

var token = new ForEachToken(new Split { Content = "<%FOREACH lines%>" });
