RemovePreviousCharsToken

class in Toshal.Template.Tokens, assembly Toshal.Template

A parsed <%REMOVE_PREVIOUS n%> tag. The processor removes the last n characters written so far, or all of them when fewer were written. It is useful to drop a trailing separator, such as the last comma of a list.

Remarks

Known issue: a negative n, such as <%REMOVE_PREVIOUS -1%>, is accepted by the parser and then makes the processor throw ArgumentOutOfRangeException. See docs/known-issues.md.

Example

// <%FOREACH tags%><%CONTEXT_AS_STRING%>, <%ENDFOR%><%REMOVE_PREVIOUS 2%>   writes   a, b

Parameters

Exceptions

Example

var token = new RemovePreviousCharsToken(new Split { Content = "<%REMOVE_PREVIOUS 2%>" });   // token.CharCount == 2
