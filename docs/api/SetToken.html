SetToken

class in Toshal.Template.Tokens, assembly Toshal.Template

A parsed <%SET name%> ... <%ENDSET%> block. The processor writes the inner tokens into a variable instead of the output. A later <%=name%> writes the variable, and the variable wins over the token value provider.

Remarks

Where a variable is visible: a SET at the top or inside IF is visible to everything after it. A SET inside WITH, PROCESS_TEMPLATE, HEADER, FOOTER, NORECORD, BEFOREROW or AFTERROW stays inside that block. A SET inside a ROW (or FIRSTROW, ALTROW, LASTROW) is visible to the rest of that row, to the AFTERROW part, and to the BEFOREROW and ROW parts of the later rows of the same loop, but not after the loop.

Example

// <%SET greeting%>Hello <%=Name%><%ENDSET%><%=greeting%>, <%=greeting%>!

Constructors

Reads the variable name and attributes of the tag. The parser calls it and then fills InnerTokens.

Parameters

split
The SET tag.

Exceptions

The tag has no name.
InvalidTokenAttributeException
The attributes are not written as name="value".

Example

var token = new SetToken(new Split { Content = "<%SET greeting%>" });
