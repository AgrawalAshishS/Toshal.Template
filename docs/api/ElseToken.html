ElseToken

class in Toshal.Template.Tokens, assembly Toshal.Template

The <%ELSE%> part of an IF block. It is the FalsePart of the last IF or ELSEIF.

Example

var token = (ConditionToken)new Parser().Parse("<%IF paid%>Thanks<%ELSE%>Please pay<%ENDIF%>")[0];
var elsePart = (ElseToken)token.FalsePart!;   // elsePart.InnerTokens holds "Please pay"

Constructors

ElseToken(Split split)

Creates the token. The parser calls it and then fills InnerTokens.

Parameters

split
The ELSE tag. Its line and column are copied.

Example

var token = new ElseToken(new Split { Content = "<%ELSE%>" });
