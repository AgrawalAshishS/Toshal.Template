ProcessorArgs

class in Toshal.Template, assembly Toshal.Template

The input of Process: the parsed template and the top context object.

Example

var args = new ProcessorArgs(new Parser().Parse(templateText)) { Context = order };
string text = processor.Process(args).ToString();

Constructors

ProcessorArgs(List<IToken> tokenList)

Creates the input for one run of the processor.

Parameters

tokenList
The tokens that Parse returned. They are not changed, so the same list can be processed many times.

Exceptions

ArgumentNullException
tokenList is null.

Example

List<IToken> tokens = new Parser().Parse("Hello <%=Name%>");
var args = new ProcessorArgs(tokens);
