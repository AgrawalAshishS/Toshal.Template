TokenAttributeDictionary

class in Toshal.Template.Tokens, assembly Toshal.Template

The attributes of a tag, such as format="0.00" in <%=Total format="0.00"%>. Keys are the attribute names in lower case. Values keep the case the template author wrote, in every tag. A quoted value may contain spaces.

Remarks

Case rules: the names the library itself uses (the tag name, such as total, and the FOREACH name of a REUSE_FOREACH) and the attribute names are lower case. Attribute values are your own settings, so they keep their case. When you want to compare a value without case, use LowerCaseValues or GetLowerCaseValue: the parser fills a lower case copy of every value while it parses, so nothing is lower cased again for each run of the processor.

Warning: it is a normal, case sensitive dictionary with lower case keys. Use GetValue, or read it with a lower case key: attributes["format"] works, attributes["Format"] throws KeyNotFoundException.

The same attribute twice in one tag makes the parser throw InvalidTokenAttributeException.

Example

var token = (NamedToken)new Parser().Parse("<%=Total format=\"0.00\"%>")[0];
string format = token.Attributes.GetValue("Format", "0");   // "0.00"

Properties

IReadOnlyDictionary<string, string> LowerCaseValues { get; }

Gets the same attributes with the values in lower case (invariant culture), for example n2 for format="N2". The parser fills it together with the dictionary itself.

Remarks

Warning: only the parser fills this copy. Entries that you add to the dictionary yourself, with Add or the indexer, are not in it.

Example

// <%IF Weight unit="KG"%>
bool kilograms = args.Attributes.LowerCaseValues.TryGetValue("unit", out var unit) && unit == "kg";

Methods

string GetLowerCaseValue(string attributeName, string defaultValue)

Gets an attribute value in lower case, or a default when the attribute is missing. The name is not case sensitive. The value comes from LowerCaseValues, which the parser fills.

Parameters

attributeName
The attribute name.
defaultValue
The value to return when the attribute is missing. It is returned as given, not lower cased.

Returns

The attribute value in lower case, or defaultValue.

Exceptions

ArgumentNullException
attributeName is null.

Example

// <%=Total Currency="INR"%>
string currency = attributes.GetLowerCaseValue("currency", "usd");   // "inr"
