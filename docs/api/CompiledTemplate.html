CompiledTemplate

abstract class in Toshal.Template.Compiled, assembly Toshal.Template.Compiled

The base class of a compiled template: a C# class made at build time from a .ctt file by Toshal.Template.Generator or by the toshal-template tool. The template text is already turned into code, so no parser runs and no token list is walked at run time.

Remarks

The generated class gets its data from partial methods that you write in the other half of the class (a stub is made once for you): TokenValue (or WriteToken) for <%=name%>, Condition for IF and ELSEIF, Loop for FOREACH and REUSE_FOREACH, With for WITH and SubTemplate for PROCESS_TEMPLATE. Only the methods for the tags the template uses are declared.

The text is the same as Processor writes for the same template and the same provider answers.

A call of Process keeps its state in its own objects, so one instance can be used from many threads at once, as long as your partial methods are safe for that.

Example

// Templates/Hello.ctt:   Hello <%=Name%>!
// Hello.cs (the stub, filled in by you):
public partial class Hello
{
    private partial string? TokenValue(TokenArgs args) => args.Name switch
    {
        "name" => ((Customer)args.Context!).Name,
        _ => null,
    };
}

string text = new Hello().Process(customer).ToString();   // "Hello Asha!"

static TokenAttributeDictionary Attributes(params string[] namesAndValues)

Makes the attributes of one tag, with their lower case copy. Generated code calls it once per tag, in a static field.

Parameters

namesAndValues
Pairs of lower case attribute name and value as written.

Returns

The attributes.

Exceptions

namesAndValues is null.

The array has an odd length, or a name is repeated.

Example

private static readonly TokenAttributeDictionary A0 = Attributes("format", "0.00");
StringBuilder Process(object context = null)

Writes the template with the given top context and returns the text.

Parameters

context
The top context. Your partial methods get it as Context for tags outside any FOREACH or WITH. When it is not null it is also the first entry of ParentContext.

Returns

A new StringBuilder with the text.

Remarks

Exceptions thrown by your partial methods are not caught; they reach the caller.

Example

string text = new OrderConfirm().Process(order).ToString();
void Process(object context, StringBuilder output)

Writes the template with the given top context and appends the text to a builder you give. Reuse one builder (call Clear between runs) to avoid a new builder, its growth and the copy of ToString() for every run.

Parameters

context
The top context, as for Process.
output
The builder to append to. Text already in it stays.

Exceptions

ArgumentNullException
output is null.

Remarks

<%REMOVE_PREVIOUS n%> and <%REMOVE_PREVIOUS_NEW_LINE%> remove only text that this call wrote, never text that was in output before the call.

Exceptions thrown by your partial methods are not caught; they reach the caller. The text written before the exception stays in output.

Example

var template = new OrderConfirm();
var output = new StringBuilder();
foreach (var order in orders)
{
    output.Clear();
    template.Process(order, output);
    writer.Write(output);
}
static void ProcessSubTemplate(CompiledTemplate template, StringBuilder output, object context, TemplateRun run, TemplateScope scope, string indent)

Does <%PROCESS_TEMPLATE name%>: writes another compiled template in place, with the current context. Its SET variables stay inside it. When indent is not empty, every line of it after the first gets the indent.

Parameters

template
The sub template your SubTemplate method returned. Null writes nothing.
output
The builder being written.
context
The current context.
run
The state of this call.
scope
The SET variables of the current block; the sub template sees them.
indent
The spaces or tabs in front of the tag when it is alone on its line, else empty.

Example

ProcessSubTemplate(this.SubTemplate(run.ProcessTemplateArgs("footer", A0, context)), output, context, run, ref scope, "    ");
