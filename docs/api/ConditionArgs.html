ConditionArgs

class in Toshal.Template, assembly Toshal.Template

The arguments of ConditionValueProvider for an <%IF name%> or <%ELSEIF name%> tag.

Remarks

For <%IF not Paid%> the name is paid. Return whether paid is true; the processor applies the not.

Example

processor.ConditionValueProvider = args => args.Name == "paid" && ((Invoice)args.Context!).Paid;

Constructors

ConditionArgs(ConditionArgs args, object context)

Creates arguments for a child object: same name and attributes, a new context, and the old context added at the end of a copy of the parent contexts. Use it when a provider hands part of the work to another provider.

Parameters

args
The arguments to copy. They are not changed.
context
The new context. It can be null.

Example

var child = new ConditionArgs(args, customer.Address);   // child.ParentContext ends with customer
ConditionArgs(ConditionToken token, object context, List<object> parentContext)

Creates the arguments for a condition tag. The processor calls it; you need it only to test a provider on its own.

Parameters

token
The parsed condition tag. Its name and attributes are copied.
context
The current context. It can be null.
parentContext
The contexts around the tag, outermost first. It is stored as is, not copied.

Example

var token = (ConditionToken)new Parser().Parse("<%IF paid%>x<%ENDIF%>")[0];
bool result = myProvider(new ConditionArgs(token, invoice, new List<object?> { invoice }));
