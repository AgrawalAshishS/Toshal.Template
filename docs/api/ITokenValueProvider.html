ITokenValueProvider

interface in Toshal.Template.Signatures, assembly Toshal.Template

The shape of a class that gives the text of <%=name%> tags. Its method matches TokenValueProvider.

Remarks

The Processor does not use this interface; it has delegate properties. The interface is a ready made shape for a provider class: implement it, then assign the method to the matching property of the processor.

Example

processor.TokenValueProvider = myProvider.TokenValueProvider;

Methods

string TokenValueProvider(TokenArgs args)

Gives the text for the named value tag.

Parameters

args
The name, attributes and contexts of the tag.

Returns

The text to write. Null or an empty string writes nothing.

Example

public string? TokenValueProvider(TokenArgs args) => ((Customer)args.Context!).Name;
