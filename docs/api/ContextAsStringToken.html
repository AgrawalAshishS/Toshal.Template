ContextAsStringToken

class in Toshal.Template.Tokens, assembly Toshal.Template

A parsed <%CONTEXT_AS_STRING%> tag. The processor writes ToString() of the current context, or nothing when the context is null. It needs no provider, so it is handy for a list of strings or numbers.

Example

// With a loop provider that returns new[] { "a", "b" }:
// <%FOREACH tags%>#<%CONTEXT_AS_STRING%> <%ENDFOR%>   writes   #a #b

Constructors

ContextAsStringToken(Split split)

Creates the token. The parser calls it.

Parameters

split
The tag. Its line and column are copied.

Example

var token = new ContextAsStringToken(new Split { Content = "<%CONTEXT_AS_STRING%>" });
