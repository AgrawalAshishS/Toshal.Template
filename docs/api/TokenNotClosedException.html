TokenNotClosedException

class in Toshal.Template.Exceptions, assembly Toshal.Template

Thrown by Parse when a block has no end tag: IF without ENDIF, FOREACH without ENDFOR, WITH without ENDWITH, SET without ENDSET, or a FOREACH part such as <%ROW%> without <%ENDROW%>.

Example

try { new Parser().Parse("<%IF paid%>Thanks"); }
catch (TokenNotClosedException ex) { Console.WriteLine(ex.TokenName); }   // paid

Constructors
