RemovePreviousNewLineToken

class in Toshal.Template.Tokens, assembly Toshal.Template

A parsed <%REMOVE_PREVIOUS_NEW_LINE%> tag. The processor removes a \n at the end of the text written so far, and then a \r at the end. It lets you keep each tag on its own line in the template without empty lines in the output.

Remarks

Warning: it also removes a lone \r at the end, even when no \n came after it.

Example

// "Hello\r\n<%REMOVE_PREVIOUS_NEW_LINE%>World"   writes   HelloWorld
