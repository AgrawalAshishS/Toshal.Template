ProcessTemplateArgs

class in Toshal.Template, assembly Toshal.Template

The arguments of ProcessTemplateValueProvider for a <%PROCESS_TEMPLATE name%> tag.

Example

processor.ProcessTemplateValueProvider = args => parser.Parse(File.ReadAllText(args.Name + ".txt"));

Constructors

ProcessTemplateArgs(ProcessTemplateToken token, object context, List<object> parentContext)

Creates the arguments for a PROCESS_TEMPLATE tag. The processor calls it; you need it only to test a provider on its own.

Parameters

token
The parsed tag. Its name and attributes are copied.
context
The current context. It can be null.
parentContext
The contexts around the tag, outermost first. It is stored as is, not copied.

Example

var token = (ProcessTemplateToken)new Parser().Parse("<%PROCESS_TEMPLATE footer%>")[0];
var tokens = myProvider(new ProcessTemplateArgs(token, null, new List<object?>()));

Methods

string GetAttribute(string key, string defaultValue)

Gets an attribute value, or a default when the tag does not have that attribute. The key is not case sensitive.

Parameters

key
The attribute name. Must not be null.
defaultValue
The value to return when the attribute is missing.

Returns

The attribute value as written in the tag, or defaultValue.

Example

string lang = args.GetAttribute("lang", "en");
