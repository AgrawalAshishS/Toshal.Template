ConditionToken

class in Toshal.Template.Tokens, assembly Toshal.Template

A parsed <%IF name%> or <%ELSEIF name%> tag with the tokens of its true part. The word THEN at the end is optional: <%IF paid THEN%> is the same as <%IF paid%>. <%IF not paid%> is a negative condition.

Example

var token = (ConditionToken)new Parser().Parse("<%IF not Paid%>Please pay<%ELSE%>Thanks<%ENDIF%>")[0];
// token.Name == "paid", token.IsPositive == false, token.FalsePart is an ElseToken

Constructors

ConditionToken(Split split)

Reads the name, the not and the attributes from an IF or ELSEIF tag. The parser calls it.

Parameters

split
The tag. If its content starts with <%IF it is read as IF, otherwise as ELSEIF.

Exceptions

TokenMissingNameException
The tag has no name, for example <%IF %>.
InvalidTokenAttributeException
The attributes are not written as name="value".

Example

var token = new ConditionToken(new Split { Content = "<%IF paid%>" });
