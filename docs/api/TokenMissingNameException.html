TokenMissingNameException

class in Toshal.Template.Exceptions, assembly Toshal.Template

Thrown by Parse when a tag that needs a name has none, for example <%=%>, <%IF %> or <%FOREACH %>.

Example

Assert.Throws<TokenMissingNameException>(() => new Parser().Parse("<%=%>"));

Constructors

Creates the exception for the tag without a name.

Parameters

split
The tag. Its line and column are copied.

Example

throw new TokenMissingNameException(split);
