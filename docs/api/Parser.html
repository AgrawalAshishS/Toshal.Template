Parser

class in Toshal.Template, assembly Toshal.Template

Turns template text into a list of tokens. Parse a template once and give the tokens to Process as often as you like.

Remarks

Tags are written as <%...%>. The keywords (IF, FOREACH, WITH, SET, ...) are upper case and case sensitive. Names are not case sensitive: the parser lower cases them.

Warning: a parser keeps state while it works. Parse one template at a time with one instance; do not share an instance between threads.

Example

List<IToken> tokens = new Parser().Parse("Hello <%=Name%>!");

Methods

List<IToken> Parse(string templateText)

Parses a template. Plain text becomes ContentToken, each tag becomes its token, and blocks such as IF and FOREACH hold their inner tokens. A REUSE_FOREACH tag is linked to its FOREACH before the method returns.

Parameters

templateText
The template. Must not be null. An empty string gives an empty list.

Returns

The top level tokens, in template order.

Exceptions

TokenMissingNameException
A tag that needs a name has none, for example <%=%>.
TokenNotClosedException
A block has no end tag, for example IF without ENDIF.
InvalidTokenAttributeException
The attributes of a tag are not written as name="value".
ForEachMissingForReuseException
A REUSE_FOREACH names a FOREACH that is not in the template.
ParserException
An unknown tag, an end tag without its start, or a REMOVE_PREVIOUS count that is missing, not a whole number, or negative. All the exceptions above derive from it.
ArgumentException
Known issue: REUSE_FOREACH names a FOREACH name that is used more than once. See docs/known-issues.md.

Example

var parser = new Parser();
List<IToken> tokens = parser.Parse("<%IF vip%>Dear <%=Name%><%ELSE%>Hello<%ENDIF%>");
